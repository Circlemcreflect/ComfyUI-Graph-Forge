## Features

- Advanced JSON workflow templates optimized for rapid text-to-image, image-to-image, and AI video generation pipelines.
- Workflow automation scripts to streamline repetitive batch processing, model switching, and output directory organization tasks.
- Custom node configuration presets for popular extensions (e.g., ControlNet, IPAdapter, AnimateDiff, WAS Node Suite) for enhanced consistency.
- Quick-switch macros and custom keybindings for seamless navigation between complex node graphs, the queue panel, and the manager.
- Pre-configured VRAM optimization profiles (e.g., specific `--highvram` or `--normalvram` args, model casting) for efficient generation on varying hardware.
- Comprehensive documentation and step-by-step setup guides for all included workflows, custom nodes, and modules.
- Integration examples and bridge scripts for third-party creative applications (e.g., Adobe Photoshop via WebSocket, Blender, OBS).
- System resource optimization configs for faster graph execution and reduced memory fragmentation during heavy, multi-pass generations.
- Ready-to-use upscaling, inpainting, and animation prompt sets with automated latent space manipulation routines.

## Requirements

- Windows 10/11 (or Linux)
- Python 3.10+ and Git installed
- Installed ComfyUI (standalone or portable version)
- NVIDIA GPU with sufficient VRAM (recommended for optimal performance)

## Usage

To utilize the included resources, download the package using the link above and extract the contents to a local directory. Run the provided setup utility (`Setup.exe` or `Install.ps1`) to integrate the custom JSON workflows, manager configs, and automation scripts directly into your ComfyUI `user/default/workflows` and `custom_nodes` directories. Follow the on-screen prompts to complete the configuration process. For detailed customization and advanced node usage, refer to the `GUIDE.md` file included in the archive.
